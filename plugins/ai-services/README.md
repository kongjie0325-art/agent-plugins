# AI 服务插件

| 服务 | 接入方式 | 说明 |
|------|---------|------|
| Suno | https://suno.ai/api | AI 音乐生成 |
| Perplexity | https://docs.perplexity.io/ | AI 搜索 |
| Hugging Face | `pip install huggingface_hub` | 模型/数据集 |
| Stability AI | https://dreamstudio.ai/ | 图像生成 |
| Firecrawl | `npx -y @firecrawl/mcp-server` | 网页→LLM 数据 |
| E2B | `npx -y @e2b/mcp-server` | 云沙箱 |
